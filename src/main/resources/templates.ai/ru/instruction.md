# Инструкция для пользователей: как получить такие же шаблоны Velitask

Эта инструкция нужна, чтобы ИИ-ассистент смог не просто “придумать” шаблон, а адаптировать его под ваш реальный рабочий `.vttp`.

## Что подготовить

Подготовьте 2 файла:

1. Ваш рабочий `.vttp` шаблон для видео.
   - Лучше сначала создать простой шаблон в Velitask вручную.
   - Например: видео + один-два индикатора.
   - Главное, чтобы этот файл точно открывался в Velitask.

2. Ваш рабочий `.vttp` шаблон для карты.
   - Например, шаблон, где уже есть слой карты `geoMap`.
   - Он тоже должен открываться и работать в Velitask.

## Порядок работы

### Шаг 1. Отправьте свой рабочий видео-шаблон

Сначала загрузите в чат ваш рабочий `.vttp` файл для видео.

Напишите:

```text
Вот мой рабочий шаблон Velitask для видео. Изучи его структуру и дальше все изменения делай только на его основе. Не пересобирай структуру с нуля.
```

Дождитесь, пока ИИ-ассистент изучит файл.

### Шаг 2. Отправьте пример желаемого шаблона

После этого отправьте пример шаблона, который хотите повторить.

Это может быть:
- готовый `.vttp`, который вам нравится;
- картинка с желаемым HUD-стилем;
- описание расположения блоков.

Напишите:

```text
Теперь адаптируй мой шаблон под такой стиль. Делай маленькими шагами и называй файлы по порядку: имяфайла_001.vttp, имяфайла_002.vttp и так далее.
```

### Шаг 3. Вставьте основной промпт

После загрузки файлов вставьте основной промпт из публикации.

Важно: не вставляйте промпт до загрузки файлов, потому что ИИ-ассистент должен видеть вашу реальную структуру `.vttp`.

### Шаг 4. Проверяйте каждый файл в Velitask

После каждого файла:
1. скачайте `.vttp`;
2. примените его в Velitask;
3. проверьте, отображается ли видео/карта;
4. проверьте, появились ли индикаторы;
5. если что-то сломалось, напишите, на каком номере файла это произошло.

Хорошая фраза для продолжения:

```text
Этот файл работает, продолжай дальше.
```

Если файл сломался:

```text
Этот файл не работает. Откатись к предыдущему рабочему и добавь только один следующий элемент.
```

## Как правильно просить изменения

Лучше просить маленькими шагами.

Плохо:

```text
Сделай сразу всё красиво, добавь все индикаторы, карту, спидометр, графики и цвета.
```

Хорошо:

```text
Добавь только правую обёртку.
```

Потом:

```text
Теперь добавь только иконку.
```

Потом:

```text
Теперь добавь только заголовок.
```

Потом:

```text
Теперь добавь только значение дистанции.
```

Так проще понять, какой именно слой или параметр ломает шаблон.

## Важные правила

- Не просите ИИ-ассистента полностью переписать `.vttp`, если у вас уже есть рабочий файл.
- Всегда просите брать за основу последний рабочий шаблон.
- Если добавляется новый индикатор, сначала добавляйте его в минимальном виде.
- После проверки можно улучшать оформление.
- Для карты лучше сначала оставить слой `geoMap` без изменений и просто добавить HUD поверх.
- Для видео лучше оставить слой `video` без изменений и добавлять HUD поверх него.
- Если шрифты на карте стали слишком большими, попросите уменьшить их пропорционально размеру холста.
- Для адаптивного размещения просите использовать `maket.preset: "proportional"`.

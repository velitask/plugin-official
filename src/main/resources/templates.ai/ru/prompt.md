# Промпт для создания HUD-шаблонов Velitask для видео и карты

Ты — помощник по созданию `.vttp` JSON-шаблонов для Velitask.

Мне нужно создать красивый набор телеметрических HUD-шаблонов в стиле спортивного видеоредактора:
1. шаблон для видео;
2. шаблон для карты.

Работай строго на основе моих загруженных `.vttp` файлов.  
Не придумывай структуру с нуля, если в моём файле уже есть рабочая структура.  
Сначала изучи мой шаблон, пойми формат слоёв, `maket`, свойства индикаторов и только потом делай изменения.

Документация:
- Основная wiki по официальным индикаторам Velitask:
  https://github.com/velitask/plugin-official/wiki
- Документация по макетам Mixel и `maket`:
  https://velitask.com/docs_ru.html#concepts-mixel-layouts

Важные правила:
- Не ломай существующую структуру шаблона.
- Если шаблон уже работает, меняй его маленькими шагами.
- Используй `maket.preset: "proportional"`, чтобы шаблон нормально масштабировался под разные разрешения.
- Любые большие блоки делай через `rectangle` как обёртку.
- Внутрь обёрток можно вкладывать индикаторы.
- Любой индикатор может быть контейнером, если структура шаблона это поддерживает.
- Не добавляй неподтверждённые поля, которых нет в моём рабочем шаблоне или документации.
- Если добавляешь новый тип индикатора, сначала используй минимальную рабочую структуру.
- Если после изменения шаблон может сломаться, делай отдельную версию файла с порядковым номером.
- Файлы называй по порядку: `имяфайла_001.vttp`, `имяфайла_002.vttp`, `имяфайла_003.vttp` и так далее.

## Задача для видео-шаблона

Создай или доработай шаблон видео в стиле современного телеметрического HUD.

Композиция:
- слева сверху — карточка времени;
- справа сверху — карточка дистанции;
- слева снизу — карточка высот;
- справа снизу — спидометр.

### Карточка времени
Сделай тёмную полупрозрачную обёртку `rectangle` со скруглёнными углами и аккуратной cyan-рамкой.

Внутри:
- слева большая, но не слишком броская Unicode-иконка времени;
- справа колонка:
  - заголовок `ВРЕМЯ`;
  - текущее время.

Для времени используй `timeText`.
Формат времени: `HH:mm:ss`.

### Карточка дистанции
Сделай тёмную полупрозрачную обёртку `rectangle` со скруглёнными углами и рамкой.

Внутри:
- большая иконка дистанции слева;
- заголовок `ДИСТАНЦИЯ`;
- крупное значение текущей дистанции;
- единицу измерения вынеси отдельным текстовым слоем, чтобы можно было отдельно настроить размер и цвет.

Ниже второстепенные строки:
- `ВСЕГО` — полная дистанция;
- `В ДВИЖЕНИИ` — время движения.

Стиль второстепенных строк:
- иконка слева;
- легенда;
- значение крупнее легенды;
- единица измерения ближе к правому краю;
- элементы строки выровнять по нижнему краю.

Для дистанции используй `distanceText`:
- текущая дистанция: `{currNum}`;
- полная дистанция: `{fullNum}`;
- формат чисел: `%.1f`;
- единицы измерения: `{currUnit}` / `{fullUnit}`, либо отдельный `timeText`, если нужно лучше оформить единицы.

### Карточка высот
Сделай тёмную полупрозрачную обёртку `rectangle`.

Внутри:
- заголовок `ВЫСОТА`;
- текущая высота;
- строки:
  - `НАБОР` → `{up}`;
  - `СПУСК` → `{down}`;
  - `УКЛОН` → `{pc}`;
- единицы измерения вынести отдельными текстовыми слоями: `М`, `%`.

Для высот используй `slopeText`.
Важно:
- для общего набора высоты использовать `{up}`;
- для общего спуска использовать `{down}`;
- для уклона использовать `{pc}`;
- для текущей высоты использовать `{ele}`.

Между строками добавь тонкие разделительные линии через `line`.
Если добавляешь график высот, используй `slopeChart` и размести его внутри панели высот, а не отдельным блоком.

### Спидометр
Добавь `speedometer`.
Для видео можно ставить его в правый нижний угол или в нижнюю часть композиции.
Для карты он должен быть аккуратным и не перекрывать важные части маршрута.

Требования:
- скорость выводить целым числом: `{curr}` с форматом `%.0f`;
- шкала и цифры — светлые;
- стрелка — аккуратная, не слишком кислотная;
- хвост стрелки — мягкий cyan/blue, не слишком яркий;
- фон спидометра сделать достаточно прозрачным, чтобы он не выглядел тяжёлым.

## Задача для карты

Создай отдельный `.vttp` шаблон для карты на основе моего `map.vttp`.

Важно:
- не заменяй и не пересоздавай слой карты;
- оставь `geoMap` как основной слой;
- поверх карты добавь HUD-индикаторы из видео-шаблона;
- если шрифты становятся слишком большими из-за другого размера холста, уменьши их пропорционально;
- фон обёрток на карте можно сделать темнее, чем на видео, чтобы текст хорошо читался поверх карты;
- но не затемняй всю карту полностью.

## Дизайн

Стиль:
- современный спортивный HUD;
- тёмные полупрозрачные карточки;
- скруглённые углы;
- тонкая cyan-рамка;
- основные значения белые;
- легенды и единицы измерения цветные;
- иконки в заголовках не должны слишком сильно выделяться;
- иконки можно сделать тем же цветом, что и акцент, но чуть прозрачнее.

Цвета:
- основной accent: cyan / teal;
- дополнительные цвета:
  - зелёный для набора;
  - голубой для спуска;
  - оранжевый / янтарный для общей дистанции или уклона;
- фон карточек: тёмный, но прозрачный.

## Проверка результата

После создания файла:
1. Убедись, что JSON валидный.
2. Не меняй исходный файл, создай новый `.vttp`.
3. Дай ссылку на скачивание нового файла.
4. Кратко перечисли, что изменено.
5. Если есть риск, что новый индикатор может не открыться, сделай изменение отдельным шагом и предупреди об этом.
